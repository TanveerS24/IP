HOW TO RUN:
1. Open an experiment folder in Visual Studio Code.
2. Install/use the Live Server extension.
3. Right-click index.html and choose "Open with Live Server".
4. Login with the demo username and password.

Note: Login is a simple classroom demonstration. The username and password are
stored in a JSON file, so this is NOT secure authentication for a real website.
Submitted form data is saved in the browser's localStorage.
